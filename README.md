# The Tirumala Verse

The Tirumala Verse is an Utsavam calendar and pilgrim guide for Tirumala and Tirupati. It makes festival dates from the TTD Panchangam and daily temple schedules easier to explore.

## Features

- Browse festival dates in an interactive calendar, with search and temple filters.
- See upcoming festival countdowns and daily Nitya Seva schedules.
- Add events to Google Calendar or share them on WhatsApp.
- Switch between English and Telugu and between light and dark themes.
